# "忽略换行符"功能改进方案

## 一、问题描述

当"忽略换行符"复选框被选中时，换行符被替换成空格，导致：

* 输入：`"今天是星期五。\r\n明天是星期六。"`

* 当前输出：`"今天是星期五。 明天是星期六。"`（多了一个空格）

* 期望输出：`"今天是星期五。明天是星期六。"`（无空格）

## 二、问题分析

**问题代码位置**：`TextSplitHelper.cs` 第164-167行

```csharp
if (_currentParagraph.Length > 0)
{
    _currentParagraph.Append(" ");  // 问题：无条件添加空格
}
_currentParagraph.Append(_line);
```

**问题原因**：原设计可能是考虑英文单词之间需要空格分隔，但对于中文文本，行之间不需要添加空格。

## 三、改进方案

### 方案：直接移除空格添加逻辑

对于中文文本处理，忽略换行符意味着直接将多行文本合并为一行，不需要添加任何空格。

### 涉及文件

| 文件                                                 | 修改内容                                                                                |
| -------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `GW.TTLtoolsBox.Core/TextSplit/TextSplitHelper.cs` | 修改 `SplitTextIgnoreLineBreaks` 和 `SplitTextIgnoreLineBreaksWithDialogProtection` 方法 |

### 详细修改

#### 修改1：SplitTextIgnoreLineBreaks 方法

**位置**：第164-168行

**修改前**：

```csharp
if (_currentParagraph.Length > 0)
{
    _currentParagraph.Append(" ");
}
_currentParagraph.Append(_line);
```

**修改后**：

```csharp
if (_currentParagraph.Length > 0)
{
    // 中文文本不需要在行之间添加空格
}
_currentParagraph.Append(_line);
```

或者更简洁地：

```csharp
_currentParagraph.Append(_line);
```

#### 修改2：SplitTextIgnoreLineBreaksWithDialogProtection 方法

同样位置，移除空格添加逻辑。
