# 多音字方案多选功能实施计划

## 一、需求概述

将TTL引擎的多音字方案从单选改为多选，并相应调整UI和替换逻辑。

## 二、影响范围分析

### 2.1 需要修改的文件

| 文件                                   | 修改内容               |
| ------------------------------------ | ------------------ |
| `ITtlEngineConnector.cs`             | 接口属性改为数组           |
| `ATtlEngineConnector.cs`             | 抽象属性改为数组，替换逻辑支持多方案 |
| `CosyVoiceV3LYttlEngineConnector.cs` | 返回多方案数组（含同音字替换）    |
| `IndexTTLv2LYttlEngineConnector.cs`  | 返回多方案数组（含同音字替换）    |
| `PolyphonicReplacePanel.cs`          | UI逻辑全面调整           |
| `PolyphonicReplacePanel.Designer.cs` | 删除旧控件，调整布局         |
| `ReplaceItem.cs`                     | 支持多方案备选项           |

### 2.2 数据兼容性

* **配置存储**：从单值字符串改为多值字符串（逗号分隔）

* **向后兼容**：读取旧配置时自动转换

**与TTL引擎关联**：

关键点：判断条件是`CurrentEngine != null`（当前选择的引擎不为"无"），而不是引擎的连接状态。

```csharp
// 刷新UI状态
var currentEngine = ConnectionManager?.CurrentEngine;
if (currentEngine != null)
{
    // 选择了非"无"引擎（无论是否连接成功），锁定为引擎支持的方案
    this.clb_选择多音字方案.Items.Clear();
    foreach (var scheme in currentEngine.PolyphonicSchemes)
    {
        this.clb_选择多音字方案.Items.Add(scheme.ShowName, true);
    }
    this.clb_选择多音字方案.Enabled = false;
    // 标记为引擎设置，不写入配置
    _isEngineSetSchemes = true;
}
else
{
    // 选择了"无"引擎，允许自由选择
    this.clb_选择多音字方案.Items.Clear();
    foreach (var ps in (new PolyphonicItem().PolyphonicSchemes))
    {
        this.clb_选择多音字方案.Items.Add(ps.ShowName, false);
    }
    this.clb_选择多音字方案.Enabled = true;
    _isEngineSetSchemes = false;
    // 加载用户配置
    loadSelectedSchemes();
}
```

**说明**：

* `ConnectionManager.CurrentEngine`：当前选择的引擎实例，如果用户选择"无"引擎则为null

* 只要`CurrentEngine != null`（选择了具体引擎），就必须锁定方案选择并按引擎方案设定

* 引擎是否连接成功不影响方案锁定逻辑

**选中项保存逻辑**：

```csharp
// 只有非引擎设置时才保存
private bool _isEngineSetSchemes = false;

private void saveSelectedSchemes()
{
    if (_isEngineSetSchemes) return; // 引擎设置不保存
    
    var selectedSchemes = new List<string>();
    foreach (var item in this.clb_选择多音字方案.CheckedItems)
    {
        selectedSchemes.Add(item.ToString());
    }
    Setting.SetValue(this.clb_选择多音字方案.Name, string.Join(",", selectedSchemes));
}

private void loadSelectedSchemes()
{
    if (_isEngineSetSchemes) return; // 引擎设置不加载
    
    var savedSchemes = Setting.GetValue(this.clb_选择多音字方案.Name, string.Empty);
    var schemeArray = savedSchemes.Split(new[] { ',' }, StringSplitOptions.RemoveEmptyEntries);
    
    for (int i = 0; i < this.clb_选择多音字方案.Items.Count; i++)
    {
        var itemName = this.clb_选择多音字方案.Items[i].ToString();
        bool shouldBeChecked = schemeArray.Contains(itemName);
        this.clb_选择多音字方案.SetItemChecked(i, shouldBeChecked);
    }
}
```

### 3.3 ReplaceItem类详细修改

#### 3.3.1 新增字段

```csharp
/// <summary>
/// 选中的方案索引数组
/// </summary>
private int[] _selectedSchemeIndices = new int[0];

/// <summary>
/// 备选项来源映射（索引 -> (方案索引, 替换字符串索引)）
/// </summary>
private List<(int schemeIndex, int replaceIndex)> _alternativeSourceMap = new List<(int, int)>();
```

#### 3.3.2 修改AlternativeTexts属性

```csharp
public string[] AlternativeTexts
{
    get
    {
        List<string> outValue = new List<string>();
        _alternativeSourceMap.Clear();

        outValue.Add(_none_Select_Text);
        _alternativeSourceMap.Add((-1, -1)); // 不替换的占位

        foreach (int schemeIdx in _selectedSchemeIndices)
        {
            var scheme = UsedPolyphonicItem.PolyphonicSchemes[schemeIdx];
            for (int i = 0; i < scheme.ReplaceStrings.Length; i++)
            {
                outValue.Add(scheme.ReplaceStrings[i]);
                _alternativeSourceMap.Add((schemeIdx, i));
            }
        }

        return outValue.ToArray();
    }
}
```

#### 3.3.4 修改UpdateReplaceText方法

```csharp
public void UpdateReplaceText(string newReplaceText)
{
    if (newReplaceText == null)
    {
        _selectedReplaceStringIndex = -1;
        _selectedSchemeIndex = -1;
    }
    else
    {
        // 从备选项映射中查找来源
        for (int i = 1; i < _alternativeSourceMap.Count; i++) // 跳过[不替换]
        {
            var (schemeIdx, replaceIdx) = _alternativeSourceMap[i];
            var scheme = UsedPolyphonicItem.PolyphonicSchemes[schemeIdx];
            if (scheme.ReplaceStrings[replaceIdx] == newReplaceText)
            {
                _selectedSchemeIndex = schemeIdx;
                _selectedReplaceStringIndex = replaceIdx;
                break;
            }
        }
    }

    IsReplaceTextUpdated = true;
}
```
