# 任务进度详情修复方案

## 问题描述

软件启动时，如果之前有正在执行的任务，当TTL引擎尚未启动（软件提示"连接失败"）时：
- 任务状态正确变为"排队中"
- 但进度详情（`ProgressDetail`）仍然显示之前的"正在生成第xx段"
- 应该显示"等待TTL引擎连接..."

## 问题根因

在 [VoiceGenerationPanel.cs:2310-2315](file:///d:/User%20Data/guanw@hotmail.com/我的私有云/GW's%20Data/我的开发/GWs/TTL工具箱/TTL%20Tools%20Box%20V1.0/GW.TTLtoolsBox.WinFormUi/UI/Panels/VoiceGenerationPanel.cs#L2310-2315) 的任务加载逻辑中：

```csharp
if (voiceTask.Status == VoiceGenerationTaskStatus.正在生成 ||
    voiceTask.Status == VoiceGenerationTaskStatus.排队中)
{
    voiceTask.Status = VoiceGenerationTaskStatus.排队中;
    hasInterruptedTask = true;
}
```

代码将状态改为"排队中"，但**没有更新 `ProgressDetail`**。`ProgressDetail` 在第2300行直接从保存的任务数据中读取，保留了之前的值（如"正在生成第xx段"）。

## 解决方案

在将任务状态改为"排队中"时，同时更新 `ProgressDetail` 为"等待TTL引擎连接..."。

### 修改位置

**文件**: `GW.TTLtoolsBox.WinFormUi/UI/Panels/VoiceGenerationPanel.cs`

**修改内容**: 第2310-2315行

**修改前**:
```csharp
if (voiceTask.Status == VoiceGenerationTaskStatus.正在生成 ||
    voiceTask.Status == VoiceGenerationTaskStatus.排队中)
{
    voiceTask.Status = VoiceGenerationTaskStatus.排队中;
    hasInterruptedTask = true;
}
```

**修改后**:
```csharp
if (voiceTask.Status == VoiceGenerationTaskStatus.正在生成 ||
    voiceTask.Status == VoiceGenerationTaskStatus.排队中)
{
    voiceTask.Status = VoiceGenerationTaskStatus.排队中;
    voiceTask.ProgressDetail = "等待TTL引擎连接...";
    hasInterruptedTask = true;
}
```

## 影响范围

- 仅影响软件启动时中断任务的恢复逻辑
- 不影响正常运行时的任务状态切换
- 与现有代码风格一致（参考 [VoiceGenerationTaskQueue.cs:506](file:///d:/User%20Data/guanw@hotmail.com/我的私有云/GW's%20Data/我的开发/GWs/TTL工具箱/TTL%20Tools%20Box%20V1.0/GW.TTLtoolsBox.WinFormUi/Manager/VoiceGenerationTaskQueue.cs#L506) 中类似处理）
