# 任务进度问题综合分析

## 问题描述

上次退出时有任务正在执行，本次启动软件后，即使引擎处于已连接状态，任务依然是排队中，并且提示"等待TTL引擎连接"。

## 问题根因分析

### 代码流程追踪

1. **软件启动时**：
   - `MainForm` 初始化各个面板
   - `_voiceGenerationPanel.LoadData()` → `load语音生成任务清单()`
   - 加载中断的任务，设置状态为"排队中"，设置 `ProgressDetail = "等待TTL引擎连接..."`
   - 调用 `RequestEngineConnection?.Invoke()`（第2359行）

2. **RequestEngineConnection 触发**：
   - 调用 `checkAndConnectTtlEngineWhenTaskStarts()`（MainForm.cs:1470-1478）
   ```csharp
   private void checkAndConnectTtlEngineWhenTaskStarts()
   {
       var status = _ttlSchemePanel?.ConnectionStatus ?? TtlEngineConnectionStatus.未连接;
       if (status == TtlEngineConnectionStatus.未连接 ||
           status == TtlEngineConnectionStatus.连接失败)
       {
           _ttlSchemePanel?.StartConnectTtlEngine();
       }
   }
   ```

3. **问题所在**：
   - 如果引擎**已经处于"已连接"状态**（比如之前的连接还保持着）
   - `checkAndConnectTtlEngineWhenTaskStarts()` 检测到状态是"已连接"，**不会做任何事情**
   - 因此不会触发 `StartConnectTtlEngine()`
   - 也不会调用 `TryResume()`

4. **TryResume 的触发时机**：
   - 只在引擎连接状态**变为**"连接成功"时才会被调用（TtlSchemePanel.cs:264）
   - 如果引擎一开始就是"已连接"，这个事件不会触发

### 根本原因

`checkAndConnectTtlEngineWhenTaskStarts()` 方法只处理了"未连接"和"连接失败"的情况，**遗漏了"已连接"的情况**。

当引擎已经连接时，应该直接调用 `TryResume()` 来恢复中断的任务。

## 解决方案

修改 `MainForm.cs` 中的 `checkAndConnectTtlEngineWhenTaskStarts()` 方法：

**修改前**：
```csharp
private void checkAndConnectTtlEngineWhenTaskStarts()
{
    var status = _ttlSchemePanel?.ConnectionStatus ?? TtlEngineConnectionStatus.未连接;
    if (status == TtlEngineConnectionStatus.未连接 ||
        status == TtlEngineConnectionStatus.连接失败)
    {
        _ttlSchemePanel?.StartConnectTtlEngine();
    }
}
```

**修改后**：
```csharp
private void checkAndConnectTtlEngineWhenTaskStarts()
{
    var status = _ttlSchemePanel?.ConnectionStatus ?? TtlEngineConnectionStatus.未连接;
    if (status == TtlEngineConnectionStatus.未连接 ||
        status == TtlEngineConnectionStatus.连接失败)
    {
        _ttlSchemePanel?.StartConnectTtlEngine();
    }
    else if (status == TtlEngineConnectionStatus.连接成功)
    {
        _voiceGenerationPanel?.TryResumeQueue();
    }
}
```
