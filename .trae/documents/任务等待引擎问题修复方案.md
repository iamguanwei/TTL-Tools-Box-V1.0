# 任务等待引擎问题修复方案

## 问题描述

当软件启动后，如果语音生成列表中的所有任务都已经完成后，过一段时间，再添加一个任务：

* 任务状态显示"排队中"

* 进度详情显示"等待TTL引擎连接..."

* 但窗口下方显示的引擎状态是"已连接"

## 问题分析

### 代码流程追踪

1. **添加任务时**：调用 `AddTask()` → 如果勾选"自动开始任务"，调用 `Start()`
2. **Start() 方法**：调用 `ProcessNextTask()` → `ProcessNextTaskAsync()`
3. **ProcessNextTaskAsync() 中的连接检查**（第443-455行）：

   ```csharp
   var connectionStatus = _getConnectionStatus?.Invoke() ?? TtlEngineConnectionStatus.未连接;
   if (connectionStatus != TtlEngineConnectionStatus.连接成功)
   {
       nextTask.ProgressDetail = "等待TTL引擎连接...";
       RequestEngineConnection?.Invoke(this, EventArgs.Empty);
       return;
   }
   ```

### 根因分析

**问题根源**：`_connectionStatus` 字段存在线程可见性问题。

在 [TtlEngineConnectionManager.cs](file:///d:/User%20Data/guanw@hotmail.com/我的私有云/GW's%20Data/我的开发/GWs/TTL工具箱/TTL%20Tools%20Box%20V1.0/GW.TTLtoolsBox.Core/TtlEngine/TtlEngineConnectionManager.cs) 中：

1. `_connectionStatus` 字段（第417行）没有使用 `volatile` 关键字
2. 该字段在多个线程中被访问和修改：

   * **定时器线程**：`ReconnectTimerCallback` → `ConnectAsync` → `UpdateConnectionStatus`

   * **UI线程**：`ProcessNextTaskAsync` 通过委托读取 `_connectionManager.ConnectionStatus`
3. 在多线程环境下，一个线程的修改可能不会立即对其他线程可见

### 验证定时器的影响

验证定时器每60秒触发一次（`VerifyIntervalSeconds = 60`）：

```csharp
// 第542-545行
else if (_connectionStatus == TtlEngineConnectionStatus.连接成功)
{
    _ = ConnectAsync();  // 连接成功时也会重新验证
}
```

在验证过程中，`ConnectAsync()` 会：

1. 调用 `_currentEngine.GetConnectionStatus()` 检查引擎实际状态
2. 如果引擎返回"连接成功"，更新状态并重启验证定时器
3. 如果引擎返回其他状态，会尝试重新连接

这个过程中状态可能短暂变化，加上线程可见性问题，导致 `ProcessNextTaskAsync` 读取到旧值。

### 与之前修改的关系

**之前的修改不影响此问题**。之前修改的是任务加载时的 `ProgressDetail` 更新，与运行时的连接状态检查无关。

## 解决方案

### 修改内容

在 `TtlEngineConnectionManager.cs` 第417行，将 `_connectionStatus` 字段声明为 `volatile`：

**修改前**：

```csharp
private TtlEngineConnectionStatus _connectionStatus = TtlEngineConnectionStatus.未连接;
```

**修改后**：

```csharp
private volatile TtlEngineConnectionStatus _connectionStatus = TtlEngineConnectionStatus.未连接;
```

**优点**：

* 修改量最小

* 确保多线程环境下的可见性

* 不改变现有逻辑

## 实施步骤

1. 修改 `TtlEngineConnectionManager.cs` 第417行，添加 `volatile` 关键字
