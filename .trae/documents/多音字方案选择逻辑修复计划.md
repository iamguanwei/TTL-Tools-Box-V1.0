# 多音字方案选择逻辑修复计划

## 一、问题分析

### 问题1：方案列表只显示引擎支持的方案
**现状**：当选择了某个TTL引擎时，`refresh多音字替换Ui()`方法会清空列表并只添加引擎支持的方案。

**预期**：应该显示所有方案，只是当前引擎使用的方案被选中。

### 问题2：切换面板后勾选被清空
**现状**：选择"无"引擎时，勾选某些方案后切换面板再回来，勾选项目被清空。

**原因**：
1. 初始化代码在面板显示时重新执行，清空并重新添加items
2. `loadSelectedSchemes()`只在`_isEngineSetSchemes`为false时调用
3. 但初始化时items被重新添加后，没有重新加载勾选状态

### 问题3：开始替换按钮始终灰色
**现状**：勾选后按钮始终灰色。

**原因**：勾选后没有触发UI刷新来更新按钮状态。

## 二、修复方案

### 2.1 修改`refresh多音字替换Ui()`方法

**修改逻辑**：
1. 始终显示所有方案（不清空列表）
2. 根据引擎状态设置勾选状态：
   - 有引擎：勾选引擎支持的方案，禁用控件
   - 无引擎：加载用户配置的勾选状态，启用控件

```csharp
private void refresh多音字替换Ui()
{
    Action action = () =>
    {
        string outputText = this.tb_最终文本.Text;
        bool outputTextHasContent = outputText.Length > 0;

        // ... 其他UI更新 ...

        var currentEngine = ConnectionManager?.CurrentEngine;
        
        // 确保列表中有所有方案（仅首次或列表为空时添加）
        if (this.clb_选择多音字方案.Items.Count == 0)
        {
            foreach (var ps in (new PolyphonicItem().PolyphonicSchemes))
            {
                this.clb_选择多音字方案.Items.Add(ps.ShowName, false);
            }
        }

        if (currentEngine != null)
        {
            // 选择了非"无"引擎，勾选引擎支持的方案并锁定
            var engineSchemeNames = currentEngine.PolyphonicSchemes.Select(s => s.ShowName).ToHashSet();
            for (int i = 0; i < this.clb_选择多音字方案.Items.Count; i++)
            {
                var itemName = this.clb_选择多音字方案.Items[i].ToString();
                this.clb_选择多音字方案.SetItemChecked(i, engineSchemeNames.Contains(itemName));
            }
            this.clb_选择多音字方案.Enabled = false;
            _isEngineSetSchemes = true;
        }
        else
        {
            // 选择了"无"引擎，加载用户配置并允许自由选择
            loadSelectedSchemes();
            this.clb_选择多音字方案.Enabled = !_do多音字替换Working;
            _isEngineSetSchemes = false;
        }

        // ... 按钮状态更新 ...
    };

    UpdateUi(action);
}
```

### 2.2 修改`loadSelectedSchemes()`方法

**修改逻辑**：移除`_isEngineSetSchemes`检查，因为调用方已经控制了调用时机。

```csharp
private void loadSelectedSchemes()
{
    var savedSchemes = Setting.GetValue(this.clb_选择多音字方案.Name, string.Empty);
    var schemeArray = savedSchemes.Split(new[] { ',' }, StringSplitOptions.RemoveEmptyEntries);

    for (int i = 0; i < this.clb_选择多音字方案.Items.Count; i++)
    {
        var itemName = this.clb_选择多音字方案.Items[i].ToString();
        bool shouldBeChecked = schemeArray.Contains(itemName);
        this.clb_选择多音字方案.SetItemChecked(i, shouldBeChecked);
    }
}
```

### 2.3 删除初始化代码中的方案列表填充

**修改位置**：构造函数或初始化方法中

**修改逻辑**：删除初始化时填充方案列表的代码，改为在`refresh多音字替换Ui()`中统一处理。

### 2.4 添加勾选状态变化事件处理

**新增逻辑**：当用户勾选/取消勾选方案时，触发按钮状态刷新。

```csharp
// 在Designer.cs中添加事件
this.clb_选择多音字方案.ItemCheck += new System.Windows.Forms.ItemCheckEventHandler(this.clb_选择多音字方案_ItemCheck);

// 在PolyphonicReplacePanel.cs中添加事件处理
private void clb_选择多音字方案_ItemCheck(object sender, ItemCheckEventArgs e)
{
    // 延迟刷新按钮状态（因为ItemCheck事件在勾选状态改变前触发）
    this.BeginInvoke(new Action(() =>
    {
        this.bt_开始替换最终文本中的多音字.Enabled =
            !_do多音字替换Working &&
            this.clb_选择多音字方案.CheckedItems.Count > 0 &&
            this.tb_最终文本.Text.Length > 0 &&
            _savedPolyphonicItemArray.Length > 0;
    }));
}
```
